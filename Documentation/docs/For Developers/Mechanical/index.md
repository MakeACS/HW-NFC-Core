# Mechanical Overview

This section goes over the mechanical design, assembly, and integration for the MakeACS Core.

All mechanical design for the Core is done in Autodesk Fusion, with the most up-to-date board design file. 

On major release, an outjob package is exported, which includes;
* Bill of Materials
* STEP and STL files for all components
* Notes on the manufacture of components

This outjob is preserved for the version number of the device (inherited from the hardware) for posterity.
