# NFC Core

This is the repository for the firmware, hardware, mechanical components, and documentation of the NFC Core of the ACS hardware. 

This is also the centralized repository for hardware, firmware, and documentation used by other variants of the Core, such as the [RFID Core](https://github.com/MakeACS/HW-RFID-Core).
