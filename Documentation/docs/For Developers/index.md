# For Developers

!!! warning
    This section of the documentation is intended for **developer use**, if you are looking for information on the deployment, configuration, and/or use of the MakeACS Core, check out the [User Manual](/User%20Manual) instead!

Navigate using the sidebar to find specific information in one of the following categories:

* Firmware: embedded firmware running on the hardware, as well as information on OTAs and similar.
* Hardware: component-level electrical design of the system.
* Mechanical: mechanical design of the enclosure, mounts, etc.
* Software: configuration software used to change settings in the Core with a graphical interface.
